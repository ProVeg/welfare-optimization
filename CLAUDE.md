# welfare-optimization

A Python project that models and simulates animal welfare subject to biophysical, socio-economic, and intrinsic constraints.

- `literature/` — background papers and notes (theory, models, welfare limits, and a `references/` citation log).
- `models/` — mathematical formulations of the welfare-optimization problem.
- `implementations/` — runnable Python implementations of those models.

Three skills are available for this project's work and hand off to each other:

- `applied-mathematician` — theoretical formulations, algorithm choice, arXiv research. Not for coding or parameter values.
- `model-engineer` — implements formulations in Python, runs simulations, produces plots/reports. Not for deriving theory or parameter values.
- `welfare-specialist` — researches welfare/agriculture/climate parameters and their values over time. Not for solvers or theorems.
