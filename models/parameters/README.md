# Parameter quick-reference tables

Scannable tables of every parameter used in [`constrained-welfare-optimization-v2.md`](../constrained-welfare-optimization-v2.md), split by how much each one changes the answer (the split the model doc itself draws in §7.1):

- [first-order-parameters.md](first-order-parameters.md) — parameters that move the result: BAU growth, headcounts, elasticities, welfare/biophysical markups, ceilings, SAD rates, demand-reduction effectiveness.
- [second-order-parameters.md](second-order-parameters.md) — parameters that shift secondary behavior (timing, magnitude of side effects) rather than the headline conclusion: welfare-range weights, campaign speed, density relief, delicacy pricing, labor ceiling, budget split, discount rate.

Each row gives the point estimate, range/uncertainty, and confidence in one line. These tables are a **navigation aid**, not the source of truth — full sourcing (papers, DOIs/arXiv IDs, verbatim quotes, scope caveats) lives only in [§7.2 of the model doc](../constrained-welfare-optimization-v2.md#72-parameter-blocks). If a number here and in §7.2 ever disagree, §7.2 wins; fix this table to match.
