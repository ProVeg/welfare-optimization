# welfare-optimization
A python project that models and simulates animal welfare subject to biophysical, socio-economic and intrinsic constraints

- [literature/](literature/) — background papers and notes, with a citation log under `literature/references/`.
- [models/](models/) — mathematical formulations of the welfare-optimization problem. See [models/parameters/](models/parameters/) for scannable tables of every parameter's point estimate, range, and confidence.
- `implementations/` — runnable Python implementations of those models (added as they land).
